# VÉRA — Óptica Contemporânea

Landing page de uma marca fictícia de óptica, desenvolvida com foco em design minimalista, elegância e animações modernas.

Projeto desenvolvido para fins de estudo, com o objetivo de praticar React, Tailwind CSS e GSAP na construção de interfaces modernas e responsivas.

## Demonstração

https://vera-xf1y.onrender.com

## Tecnologias

- React 19
- JavaScript
- Tailwind CSS 4
- GSAP
- GSAP ScrollTrigger
- React Icons
- Vite

## Funcionalidades

- Design moderno e responsivo.
- Apresentação da marca.
- Exibição de coleções de armações.
- Secção de serviços.
- Navegação entre secções.
- Animações com GSAP.
- Efeitos durante o scroll.

## Como executar localmente

1. Clonar o repositório:

   git clone https://github.com/moisesisaacdev/vera.git

2. Entrar na pasta:

   cd vera

3. Instalar as dependências:

   npm install

4. Iniciar o servidor de desenvolvimento:

   npm run dev

A aplicação estará disponível em:

http://localhost:5173

## Outros comandos

npm run build    # Gerar build de produção
npm run preview  # Visualizar build de produção
npm run lint     # Verificar código com ESLint

## Objetivo

Projeto desenvolvido para fins educativos, permitindo praticar componentização com React, estilização com Tailwind CSS, animações com GSAP e desenvolvimento de interfaces responsivas.
